Why this matters

Agents are ready to act. Most companies are not ready to let them.

Synapse makes an existing app usable by AI agents in minutes. The hard part comes next. One wrong tool call can refund the wrong people or close the wrong tickets, and there is no undo button.

Hidden instructions

Agents read customer messages, documents and web pages. Any of them can carry instructions that look like orders.

Mistakes at scale

A person makes one wrong refund. An agent can make forty before anyone notices, and each one looks reasonable on its own.

No way back

Most internal apps were never built for automated callers. They record what happened, not what an agent meant, and rarely support undo.

How it works

Rehearse. Review. Decide. Verify.

Rehearsal sits between the agent and the MCP server Synapse generates from your app. Your app is never changed.

  1. 1

    Rehearse

    Each request gets a private copy of the app and its data. Every tool call runs there and is recorded.

  2. 2

    Review

    You get a plain list of what would change, the money involved, and clear reasons for anything unusual.

  3. 3

    Decide

    Say yes and the recorded steps run on the live app. Say no and nothing happens. Risky ones need an extra tick.

  4. 4

    Verify

    Rehearsal checks the live result matches the rehearsal exactly, rolls back if it does not, and keeps a record you can trust.

Feels familiar

Synapse at the core

Your existing app, made agent ready and safe.

Synapse reads the app's code and generates the MCP server every tool call goes through. Rehearsal starts that same generated server twice, once for the private copy and once for live, and switches between them with one setting.

# the only build step for the app being protected
synapse build --local --auto --endpoints "..."

# start Rehearsal and open the link it prints
python -m rehearsal.server

Questions

Good questions, short answers.

What is Rehearsal?

A safety layer between an AI agent and an existing app. The agent works on a private copy first. Then you see exactly what it wants to change, in plain words, and you decide.

Do I have to change my app?

No. Synapse generates the MCP server from your app's existing code, and Rehearsal starts copies of the app exactly as it is. The demo store's code was never touched.

How does it decide what is risky?

With plain rules you can read. Money leaving the business, more than one customer touched in a single task, a payment above the approval limit, bulk changes, deletions and blocked tool calls. No second AI is guessing.

What if the live data changes while I am reviewing?

Rehearsal notices and holds off, so it never applies changes that no longer fit. It asks you to rehearse again instead.

What if something goes wrong while it applies the changes?

It puts the live data back the way it was before you said yes, checks that the restore worked, and tells you plainly.

Does it cost anything?

No. It runs on your own machine. The agent uses free models from Groq, OpenRouter and Gemini, and switches between them automatically when one is busy.
